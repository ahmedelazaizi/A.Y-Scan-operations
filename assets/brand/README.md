# A.Y Scan Brand Assets

الملفات الحالية هي مصادر SVG قابلة للتعديل:

- `ay-scan-mark.svg`: الأيقونة والـ app mark.
- `ay-scan-logo.svg`: lockup للخلفيات الفاتحة.
- `ay-scan-logo-dark.svg`: lockup للخلفيات الداكنة.

## الاستخدام
استخدم `mark` للأيقونة، favicon، splash، وapp icon. استخدم lockup في شاشة الدخول، التقارير، والموقع التعريفي. لا تغيّر الألوان أو النسب دون تحديث [BRAND_GUIDELINES](../../docs/BRAND_GUIDELINES.md).

## التصدير
بعد اعتماد النسخة النهائية، صدّر PNG بأحجام 16/32/48/192/512، وICO متعدد الأحجام، وPWA maskable icon. يجب أن يتم التصدير من SVG الأصلي لا من screenshot.

الألوان الأساسية: `#0A1A33`, `#12A9CF`, `#A8CE2E`, `#FFAA1D`, `#F2F6FA`.
