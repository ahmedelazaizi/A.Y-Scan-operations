# وثائق تأسيس نظام مركز التحاليل والأشعة

## طريقة المراجعة
1. ابدأ بـ [PRD](PRD.md) لتثبيت النطاق والقرارات.
2. راجع [ARCHITECTURE](ARCHITECTURE.md) للتأكد من قابلية التنفيذ والأمن.
3. استخدم [ROADMAP](ROADMAP.md) لمراجعة ترتيب البناء والبوابات.
4. راجع [TRACEABILITY](TRACEABILITY.md) للتأكد أن كل هدف قابل للاختبار.
5. اختم بـ [REVIEW_CHECKLIST](REVIEW_CHECKLIST.md) وسجّل القرارات.

## سجل الإصدار
- v0.1 — مسودة تأسيسية مبنية على صور العينة، مع فصل القرائن البصرية عن المتطلبات الملزمة.

## قرارات مفتوحة
الدولة واللوائح، الأجهزة والتكامل، حجم التشغيل، retention، PACS، مزود الرسائل، سياسة الفروع، وRPO/RTO. لا تعتبر المسودة موافقة قانونية أو طبية.
